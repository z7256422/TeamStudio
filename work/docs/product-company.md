# 28 人产品研发公司

## 组织与职责

| 团队 | 人数 | 直属岗位 |
| --- | ---: | --- |
| 产品研发管理团队 | 3 | 总项目经理、系统架构师、交付与配置经理 |
| 需求管理团队 | 4 | 需求负责人、产品经理、需求分析师、用户研究员 |
| 软件开发团队 | 6 | 软件负责人、前端、后端、嵌入式固件、数据与通信、软件测试工程师 |
| 机械设计团队 | 4 | 机械设计负责人、结构、机构、热与结构仿真工程师 |
| 硬件设计团队 | 4 | 硬件设计负责人、电路、PCB、硬件验证工程师 |
| UI 与产品设计团队 | 4 | 设计负责人、交互设计师、UI 视觉设计师、工业设计师 |
| 系统验证团队 | 3 | 系统验证负责人、系统集成测试、可靠性与量产工程师 |

研发管理团队是根节点，其余六个团队是直接子节点。28 个成员各归属一个团队，无重复角色实例或共享成员 ID。每组一名 `ProjectManager` 角色负责人，由 `team.leaderId` 明确指定；专业负责人使用中文岗位名称区分。

## 使用

- 无已存配置的新用户默认加载公司组织。已有配置保持原样，进入「团队配置 → 添加 28 人研发公司」，检查后保存；添加会保留原团队，支持撤销。新成员沿用当前团队的默认 Provider、模型、目录与权限，每位成员仍可单独修改。
- 选择小团队直接提问或交任务，由该团队负责人协调；选择产品研发管理团队则由总项目经理先按需分派部门。没有相关工作的人保持待命，不广播给 28 人。
- 旧版「新建团队」仍创建简单软件团队。选定直属负责人后启用分级调度；所有被包含的子团队都须有可识别的直属负责人。
- `outputs/product-company.json` 是可导入的完整组织配置；导入按既有功能替换当前草稿，添加模板则保留原团队。完整 28 份提示词见 `outputs/product-company-prompts.md`。

## 分级执行与反馈

总经理 → 部门负责人 → 专业成员。总经理只可派发直属成员和直接子部门负责人；部门负责人获得被裁剪到本部门子树的花名册与管理工具，普通成员只有反馈工具。服务端拒绝越级、兄弟部门访问、重复包含、循环或悬空关系。

部门负责人同时具有上下两种身份：用 `team_wait` / `team_reply_member` 管理组员；用 `team_ask_manager` 向直接上级咨询。成员提问先由直接负责人处理，需要跨部门决策时负责人带上事实、影响与建议向上升级，取得决定后回复原提问。每层等待都挂起并由事件唤醒，不新增轮询或额外推理调用。

默认每级并发 1：同一时刻各负责人最多派发一个直属工作包，深层可继续执行。这个限制不是整棵树的进程总数；总经理和部门负责人挂起时工程师仍可工作。调整上限时要考虑共享文件冲突和多部门的总资源消耗。

继续会话沿用原组织快照；返工恢复相同成员、供应商、模型的线程。当成员首次成为具有管理和向上反馈双重工具的负责人时，按既有兼容机制迁移线程并保留近期公开结果。停止上级递归停止下属并释放等待，所有层级仍只属于同一个任务和用户轮次。

## 产品工作流与交付要求

1. 总经理澄清目标与授权范围，需求团队整理需求、优先级与验收基线。
2. 系统架构师对齐软硬件、机械和交互接口；设计团队确定交互与产品外形。
3. 各专业负责人依据冻结接口按需实现，冲突通过上级协调，成员完成后可返工。
4. 各部门先验证自身成果，系统验证团队独立检查跨专业需求和候选版本。
5. 交付经理核对代码、图纸、固件、BOM 和报告版本，总经理提交完整产物与实际验证边界。

不是每个任务都要经过全部阶段。普通问题可直接答复；分析、需求和评审工作包允许报告成果；实际开发仍保留文件和验证验收。子团队完成类型按其本次分工判定，不强迫需求分析因为总目标写着“开发”而编写代码。

机械/硬件岗位不代表环境自动安装 CAD、EDA、求解器或仪器。必须核实工具与设备能力，明确区分参数规格、实际设计文件、仿真、样机和实测结果。不得伪造文件、测量、访谈或认证；采购、外发设计、投板、生产和发布按用户授权执行。

## 实现边界

- 岗位规格：`panel-src/config/company-roles.js`；提示词及独立组织实例：`company-template.js`。
- 浏览器以原 version 2 配置存储 `leaderId`；运行快照增加 `rootTeamId`、`teams`，兼容未使用层级的旧花名册。
- 服务端 `team-hierarchy.cjs` 专职验证、派发边界和子树裁剪，既有 coordinator 负责事件调度和验收。
- 组织模板不是用户资料，不包含密钥。导出产物通过 `node work/export-company.cjs` 与界面模板同步。
