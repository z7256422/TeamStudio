Team Studio {{VERSION}} — Windows 便携版

启动
1. 将 ZIP 完整解压到有写入权限的文件夹；不要直接在压缩包内运行。
2. 双击 Start.cmd，启动成功后会自动打开 http://127.0.0.1:3210。
3. 保留启动窗口。使用完毕，双击 Stop.cmd，或在启动窗口按 Ctrl+C。
   关闭服务会中断尚未结束的任务；需要继续时可以从原历史会话恢复。

运行要求
- Windows x64，支持随包附带的 Node.js 24 运行时；无需另外安装 Node/npm。
- 执行 Agent 任务需要本机已安装且可用的 Codex CLI（codex 命令），认证由所选供应商决定。
- MCP、skills 沿用当前用户的 Codex 配置；模型可使用默认供应商或自定义 API 连接。
  此包不附带 Codex、登录凭据或模型服务。
- 默认只监听 127.0.0.1，本机浏览器可访问。此版本仍使用浏览器界面。
- 通过启动窗口地址访问；直接打开 HTML 不再连接接口。外站/null Origin/非回环 Host
  一律拒绝，包括历史、审批、SSE 和预检。文件页面旧团队配置可导出后在服务页面导入。
- 新团队默认“无沙箱”，任务可访问当前用户有权限的文件和网络，无需初始化 Windows 沙箱。
  可以在任务输入框或团队配置中改为“工作区可写”或“只读”。已保存的旧团队和历史
  会话继续沿用原权限；旧团队需要切换到“无沙箱”并保存，才会改变后续新任务的默认值。

停止与重复启动
- 再次双击 Start.cmd 会打开已经运行的面板，不会另启一份服务。
- Stop.cmd 只通过本目录的控制通道关闭本包启动的服务，不按进程名称批量结束 Node/Codex。
- 端口被其他服务占用时会明确提示，不会替你关闭其他程序或自动换端口。
- 推荐使用 Stop.cmd 或 Ctrl+C，以保证最后的运行进展保存到磁盘。

配置与历史记录
- 团队、成员、界面设置保存在浏览器本地存储；可在面板中导出/导入配置。
- 运行历史保存在本包 .agent-manager/runs.sqlite，首次运行自动创建。
- 更换浏览器、域名或端口后，需要导入原来导出的团队配置。
- 本包是干净的分发包，不包含开发机历史、用户凭据、日志或任务产物。
- 迁移已有历史：先停止新旧服务，再将旧 .agent-manager 中的 runs.sqlite
  及存在的 runs.sqlite-wal、runs.sqlite-shm 一起复制到新包同名目录。
  不复制 launcher.json。历史中的工作目录仍需在当前电脑上存在。
- 更换电脑后，原 Codex 会话上下文、认证和依赖仍由本机 Codex 管理，不能仅靠复制此包迁移。
- 自定义连接保存在 .agent-manager/providers.json，Windows API Key 由当前用户加密。
  升级时停服并迁移该文件，可保留连接 ID；换电脑/系统用户后需要在界面重新填写密钥。
  团队配置导出不包含密钥或连接地址。

团队统一设置（0.15.0）
- 团队配置新增“执行接口”和“工具与能力”；接口与能力可分别选择沿用或独立配置。
- 新成员默认沿用，已有成员保留原配置，可一键让全部直属成员沿用。
- 团队修改同步到沿用成员；切换独立配置时保留当前生效值，可按需调整。
- Skills/MCP 仍是能力选择偏好，实际工具权限由本机 Codex 控制。
- 子团队与历史续聊保持各自设置；保存与导入导出仍使用兼容的 version 2。

自定义模型
1. 在“接口与能力 → 自定义模型”添加名称、Base URL、API Key、默认模型 ID。
2. 支持 Responses 流式与工具调用，例如 https://api.example.com/v1；仅支持 Chat
   Completions 的地址暂不能使用。点击“测试连接与工具调用”后保存。
3. 在“团队配置 → 执行接口”选择团队连接与默认模型，新增成员自动沿用。
   已有成员点击“让全体直属成员沿用团队设置”统一应用，最后点击“保存更改”。
   个别成员可在“Agent 配置”切换为独立配置；子团队保留自己的设置。
4. 编辑密钥留空保留，填写新值替换。任务运行时禁止修改正在使用的连接。
5. 历史会话保持原模型和供应商；连接地址变化后需恢复原地址或新建任务。
6. 在连接表单选择供应商支持的“思考强度”；例如接口要求 low/high/max 时请明确选择。
   显式强度同时用于测试和正式执行，修改后可在原会话继续；旧配置默认沿用引擎/会话设置。

自定义启动（PowerShell，在解压目录执行）
  $env:AGENT_MANAGER_PORT = '3211'
  .\Start.cmd
Stop.cmd 会自动找到该目录中已启动的实例，无需重复设置端口。
可设置 AGENT_MANAGER_DATA_DIR 指定历史存储目录。
可设置 TEAM_STUDIO_NO_BROWSER=1 禁止自动打开浏览器。

常见问题
- 浏览器没有自动打开：在浏览器手动访问启动窗口显示的网址。
- 找不到 codex：先确保 PowerShell 中 codex --version 可执行，并完成 Codex 登录。
  如需自定义 CLI，请将其目录加入 PATH 后重新启动。
- Codex 沙箱/登录/网络错误：在“接口与能力”检查引擎诊断；打包不会修复系统环境问题。
- 启动失败：启动窗口会保留具体错误。路径可包含空格和中文。

文件说明
  Start.cmd / Stop.cmd      启动和停止入口
  runtime/node.exe          随包 Node 运行时
  runtime/NODE-LICENSE.txt   Node 及其组件许可证
  outputs/                  编译后的界面与前端第三方许可证
  work/                     后端运行模块
  manifest.json             版本、运行时信息和文件 SHA-256

此为便携 ZIP，不是安装器，也不创建自启动项。
